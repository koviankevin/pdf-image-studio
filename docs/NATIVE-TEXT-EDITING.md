# 原生 PDF 文字編輯

基準：`4114f71fdadb5fc43baba5b7467282b7365b8797`。使用者同意增加 Word 匯出 PDF 的原文編輯；本次版本 0.11.0，沿用本機處理與 GitHub Pages 發布。

## 功能與驗收契約

1. 在既有每頁文字編輯器點選原字區塊或用清單選取，修改文字、黑體／明體、大小、顏色、範圍和位置。第一版針對單一水平基線、同字型與顏色的獨立文字物件；不承諾 Adobe Pro 全格式或段落、表格重排。
2. 真正移除該文字物件的 Tj／TJ／引號文字運算元，再寫入新文字，不蓋白底；舊字不再由輸出 PDF 的文字擷取取得，彩色背景、其餘文字、Form XObject、影像和未改頁面保留。只將可到達的已修改頁面資源複製到最終 PDF，避免舊內容串流作為孤立物件殘留。
3. 修改以 native 標記跟隨頁面，原文字物件 ID 與來源內容 SHA-256 綁定。原始來源不改；支持取消、編輯器與工作區復原重做、刪除此編輯恢復原稿、空字串刪原字、未失焦草稿與跨 context 專案備份。
4. PDF、PNG／JPG、剪貼簿／框選及 A4 共用組裝路徑。搜尋與原生文字擷取反映修改；排除與原區域重疊的舊 OCR 行，保留無關行與草稿原 OCR 供復原。
5. 不支援的結構明確停用，不能以蓋白或隱藏原文假裝完成。包含文字裁切、透明度、Type3、不可解碼 Unicode、右向左／垂直／字形旋轉、原稿隱藏文字、ActualText 等特殊語意替代、多行混合格式、嵌入物件內文字、行內圖片、不可靠指令對應。頁面 /Rotate 與既有裁切保持可用；超出目前可見頁面需調整。
6. 解析僅當要求原文編輯或輸出已有原文編輯時執行；只分析目前頁面，快取隨來源釋放。每頁解碼內容最多 4 MiB、串流 2,000、指令 50,000、節點 200,000、文字物件 2,000、巢狀結構 32，解碼器在擴充 buffer 前檢查上限。識別與背景預覽失敗不提交文件，支援取消識別／重試預覽，晚到的結果不覆寫新編輯器。
7. 沿用既有嚴格像素與輸出檢查、必要完整 CI；本機先測受影響行為，再由 main 同一提交發布。相容性案例增加兩項，各自有 context 與 worker-scoped 伺服器，CI 使用兩個 worker，保留 9 分鐘 suite／10 分鐘 job 上限與失敗阻擋發布。

## 邊界

此功能修改正常文字內容，非安全塗黑。原文可能出現在本機來源、草稿、備份、其他頁、字型映射、影像或文件其他資料；不承諾永久刪除所有可恢復資訊。內附字型可能與原稿不同，不能保證完全一致。商品化真人／實機驗收仍待使用者試用。

## 規範依據

- [Adobe 公開 PDF 32000-1:2008](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf)，9.4 文字物件、9.4.3 文字顯示運算元。
- [PDF Association 操作符表](https://pdfa.org/download-area/cheat-sheets/OperatorsAndOperands.pdf)。

解析以保留位元組區段的詞法讀取器定位運算元；PDF.js 解碼字形、原字型與位置，無法與頂層文字物件一一對應時拒絕。未修改第三方程式庫、未更換授權。
