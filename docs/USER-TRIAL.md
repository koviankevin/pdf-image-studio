## 試用方式

使用目前 [紙間網站](https://koviankevin.github.io/pdf-image-studio/)，先從「工作區與專案備份」新增空白工作區，再用「使用說明」中的合成範例。每項任務記錄是否獨立完成、卡住的操作與是否能自行恢復；不以開發者代做取代首次使用結果。

1. 講義整理：加入講義範例，調整頁序，把兩頁排成一張 A4，預覽並下載。
2. 辦公整理：在另一個工作區加入辦公範例，刪除一頁、加文字備註，輸出新 PDF。
3. 清晰圖片：框選局部，複製貼到常用軟體；不能複製時改用下載。記錄 DPI、長邊上限與接收軟體，確認文字可讀。
4. 保存恢復：產生 `.shijian` 備份、確認檔案下載完成，重新開啟網站，再把備份匯入空白工作區，核對頁序、標記與 A4 版面。
5. 支援資訊：找到本機資料與保存／備份狀態、隱私限制及版本；建立診斷並自行確認沒有文件內容或檔名。
