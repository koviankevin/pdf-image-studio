## 真人與實機驗收任務

全程使用示範或已去識別的文件；使用者自行提供回饋，不自動收集文件或行為。

1. 教師：加入兩份講義、調整頁序、將兩頁排在 A4、下載並確認文字可讀。
2. 辦公：加入會議資料與附件、移除一頁、加文字標記、預覽並下載新 PDF。
3. 共用：框選局部並複製／下載圖片，能說明 DPI 與長邊上限的作用。
4. 保存：下載專案備份、重新開啟、在另一個空白工作區匯入備份。
5. 支援：找到隱私說明、版本、資料管理與診斷下載；能確認診斷不含文件內容。

記錄裝置／瀏覽器、是否需協助、失敗步驟、是否能自行恢復。以實際結果判定，不以開發者操作或瀏覽器模擬取代真人／實機證據。

## 營運選擇

現階段延續 GitHub Pages、本機處理、無帳號與無追蹤的產品方向。獨立網域、安裝／離線、付費方案需依推廣或收費計畫決定；不默認購買服務、搬移資料、建立帳號系統或承諾付費支援。換網域前須安排舊網址專案匯出與新網址匯入。
