# 安全維護與支援範圍

紙間是靜態網站，文件在裝置內處理。這份程序用來維護既有防護，不代表安全認證，也不保證任意惡意 PDF 或所有裝置皆可處理。

## 相依來源與公告查核

`dependencies.json` 記錄 README 的內附版本、來源、目錄與授權。它不是完整的遞迴 SBOM；壓縮 bundle 的內含相依、fork 上游公告與沒有版本標籤的字型／語言資料仍須人工檢查。每個實際發布檔的 SHA-256 見 `dist/release-manifest.json`，可追溯改動；雜湊只證明內容吻合，不證明來源可信或沒有漏洞。

更新 PDF／OCR／ZIP 程式庫前，查閱官方 release、安全公告、授權與相依差異。從官方發布來源取得固定版本，記錄來源 URL／版本或 commit、保留授權，核對核心與 worker 配套；不要只替換主模組。若發現公告，先判定版本範圍與紙間實際啟用的路徑，再修補並測受影響功能。

可手動執行 `node scripts/audit-dependencies.mjs`，向 OSV 查詢清單中的公開套件名稱和版本。它不讀使用者文件或傳送草稿；服務失敗、未查完與有公告都不視為通過。它不是背景監控，不能取代 fork、bundle、資料檔及官方公告的人工檢視。查詢方式依 [OSV 官方 API](https://google.github.io/osv.dev/post-v1-querybatch/)。

2026-10-27 查詢上述六個 npm 版本，OSV 皆回傳零筆公告、無下一頁；這只描述該日資料庫結果。另查 [PDF.js GHSA-hq66-cqwq-w95j](https://github.com/mozilla/pdf.js/security/advisories/GHSA-hq66-cqwq-w95j)，公告的受影響版本從 5.6.83 起、修補為 6.2.108，紙間內附 5.4.624 不在其列出的範圍。後續發布仍需重新查核，不據此宣稱永久安全。

## 產品契約

- 不加入文件上傳或分析追蹤。新網路請求必須能說明來源與用途；目前程式、OCR、字型均隨站提供。
- 保留 CSP、不執行 PDF 內含腳本；輸入與 ZIP 大小、頁數、幾何及資源引用限制不可為了通過單一文件而移除。
- 草稿與專案未加密，包含已解鎖內容。共用電腦需清除；密碼不保存。裁切／標記不是敏感資訊永久遮蔽。
- 新的保存改動必須驗證上一份完整草稿、空間不足、跨分頁衝突與匯出逃生路徑；不以清除資料修復錯誤。
- 診斷只使用固定欄位與代碼；不加原始錯誤、堆疊、網址、檔名、OCR、私人識別碼或文件。安全錯誤不可導致診斷本身失效。

## 回報與處置

一般功能問題可從站內「版本與回報」先檢查診斷，再由使用者自行開啟 GitHub issue；不自動送出。公開回報只提供去識別步驟與合成文件。尚未建立私人漏洞接收管道，請勿把未公開漏洞細節、密碼或真實文件放到公開 issue；發布前由維護者確認合適的私下接收方式。沒有承諾固定回覆時間、SLA 或付費支援。

遇到文件外傳、草稿損毀或無法安全匯出的修訂，先停止推廣該版本，保留合成重現證據並依發布流程回復經驗證版本，再處理修補。不要要求使用者先清空瀏覽器資料。
