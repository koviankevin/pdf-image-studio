# 清晰 PDF

純前端 PDF 合併、頁面標記、圖片轉 PDF、中文 OCR 與高解析度圖片工具。PDF 與密碼只在記憶體內處理，不上傳、不使用 localStorage，也沒有分析追蹤。網站程式庫隨網站提供，不使用外部 CDN。

## 使用

1. 一次加入多份 PDF、JPG 或 PNG，也可隨時追加；加密檔案會要求密碼。取消密碼只跳過該檔案。
2. 每頁顯示來源檔案與原頁碼；拖曳單頁或用上移／下移按鈕排序。
3. 勾選多頁後輸入「移至第幾頁」可批次移動，位置表示移動後第一個選取頁的最終位置。可移除頁面、復原最近 30 次移動／移除；追加來源後清除復原記錄。
4. 兩種輸出共用目前的頁序與勾選狀態。可用「依目前頁碼選取」填入例如 `1, 3-5`，或留空全選。
5. 按「下載新 PDF」直接複製原始頁面，保留文字、向量與原頁尺寸。新檔案不加密，表單固定化，不保留文件書籤、附件或有效數位簽章。
6. 或選擇 150／300／450／600 DPI、PNG／JPG 後按「轉換為圖片」，再複製、逐張下載或下載 ZIP。變更頁序／選取時會清除過期圖片結果，避免輸出錯誤版本。

## 框選、旋轉與裁切

- 點縮圖或「框選／裁切」，在預覽上拖曳，或輸入左側、上方、寬度、高度百分比。滑鼠與觸控均可使用。
- 「複製框選區域」以目前 DPI 與長邊設定產生 PNG，直接寫入剪貼簿；也可下載指定 PNG／JPG 格式。這兩項不改變工作區頁面。
- 左轉／右轉可調整草稿方向；「套用旋轉與裁切」才更新工作區、PDF、拆分結果與圖片。關閉視窗則捨棄草稿。
- 頁卡的「旋轉」與工具列「旋轉選取 90°」可快速旋轉一頁或多頁。裁切與旋轉都能復原。
- PDF 裁切使用 CropBox，維持文字與向量品質，但不會永久清除框外資料；不能作為遮蔽敏感資訊的工具。

## 拆分 PDF

- 展開「拆分成多份 PDF」，可將勾選的每頁存成一份。
- 自訂範圍依目前工作區的全部頁碼，不受勾選影響。以分號或換行分組，例如 `1-3; 4-8`，或 `1,3; 2,4`。不同組可重用同一頁。
- 各份 PDF 都套用目前旋轉與裁切，依組別編號後以 ZIP 下載；最多 500 組、總計 2,000 個輸出頁次、256 MB，超限會提示分批。

## 圖片尺寸與容量

- JPG 品質可調 30%–100%；PNG 維持無損。長邊上限 0 表示不限，或輸入 64–16,384 px，只縮小、不額外放大超過所選 DPI。
- 限制長邊時等比例縮小，輸出中繼資料和結果卡顯示實際 DPI（四捨五入至整數）。這些設定不改變 PDF 檔的頁面尺寸。
- 「預估圖片檔案大小」以實際設定編碼最多三張代表頁，依平均容量估算；一至三頁時會計算全部頁面。預估不會下載，超過三頁時明確標示抽樣及不確定性。
- 尺寸／品質／選取／頁面內容改變後清除舊預估。每張轉換完成的圖片另列實際容量。

PNG 為無損；JPG 品質預設為 95%，可調整。複製時以 PNG 寫入剪貼簿。剪貼簿須 HTTPS 或 localhost，且瀏覽器允許圖片剪貼簿；失敗時會開啟圖片，供右鍵／長按複製或下載。圖片會寫入選定 DPI 的解析度中繼資料。提高 DPI 不會創造掃描原稿不存在的細節。

## 本機啟動

安裝 Node.js 後，在本目錄執行 `node serve.mjs`，開啟顯示的 Local URL。請勿直接以 file:// 開啟 HTML。

## 實作與限制

- 靜態網站：`dist/`；入口 `dist/index.html`。
- Mozilla PDF.js 5.4.624（Apache-2.0），包含 CJK 字型映射、標準字型與 WASM；fflate 0.8.3（MIT）負責 ZIP。授權文件位於 `dist/vendor/`。
- @cantoo/pdf-lib 2.11.1（MIT）負責密碼解密與原始 PDF 頁面合併；PDF 不經過圖片化。
- 逐頁渲染、縮圖預覽，渲染完即釋放 Canvas；可停止並保留已完成圖片。
- 單份 PDF 上限 100 MB、來源總計上限 150 MB、工作區上限 500 頁；每頁圖片上限 4,000 萬像素、單邊 16,384 px；本次圖片容量上限 256 MB。超限會明確提示分批或降低 DPI，不會悄悄縮圖。
- 特殊或損毀 PDF、裝置記憶體不足時仍可能無法轉換。OCR 可能出錯，沒有 AI 補畫或完整表格還原功能。
- 以 `document.modelContext` 存在時註冊可選的輸出設定工具，不依賴此 API。
- 設定與原始檔不持久保存；重新整理會清除本次工作。

PDF 渲染 API 參考：https://mozilla.github.io/pdf.js/examples/ 與 https://mozilla.github.io/pdf.js/api/。
PDF 合併與解密參考：https://github.com/cantoo-scribe/pdf-lib。


## 文字與標記

- 每頁的「文字／標記」可新增文字、半透明螢光筆、箭頭及空心方框。選工具後拖曳加入，文字可點擊加入；鍵盤使用者可用「在頁面中央加入」。
- 「選取／移動」或標記下拉選單可選擇既有標記，拖動位置、改文字／顏色／字級／線寬、刪除或復原。視窗內修改按「儲存此頁標記」才生效；取消不更動文件。
- PDF 匯出保留向量標記並嵌入繁體中文字型子集。圖片、縮圖及框選下載採用相同標記。旋轉、裁切、排序及拆分共用 PDF 座標，不會將標記貼到別頁。
- 這是新增固定內容，不是修改原稿段落，也不是永久遮蔽工具。

## 圖片轉 PDF

- PDF 與 JPG／PNG 共用加入區，可混合追加。圖片依檔案順序各成一頁，之後可以排序、旋轉、裁切、加標記。
- 加入前可展開設定選 A4 直向／橫向及留白，或依原圖片尺寸（96 DPI）建立頁面。保持比例，不裁掉內容，透明背景轉為白色。
- 為正確處理照片方向並保留畫面，圖片解碼後內嵌成 PNG；不做影像增強，也不承諾縮小容量。單張最多 4,000 萬像素。

## OCR 與文字校對

- 勾選頁面後按「辨識選取頁面的文字」。原生文字先直接擷取，完全沒有文字的頁面才以 300 DPI（長邊最多 3,500 px）做 OCR。混合文字與掃描區域的頁面只擷取既有文字，尚未做區域自動偵測。
- 支援繁體中文＋英文或英文。語言與引擎跟隨網站部署，首次使用需要下載；所有文件辨識在 Web Worker 內完成，不傳送檔案、不持久保存文件，也不使用模型快取儲存文件。
- 一次最多 100 頁，逐頁處理；可停止，保留已完成頁面。辨識中斷不影響原稿。
- 校對視窗並排原稿與逐行文字；信心低於 80 顯示「需確認」，信心分數不是正確率。文字可修改、複製或下載 TXT。原稿已有文字的頁面僅供直接擷取，不能在 OCR 視窗改寫原文。
- 按「儲存校對」後，主畫面的「下載新 PDF」自動在掃描頁加入不可見的中文字層。可搜尋／複製，原本外觀不變；拆分匯出亦保留。重新辨識會取代先前校對結果，先前狀態可用工作區復原。
- OCR 不是 Word／Excel 版面還原；手寫、低畫質、直排、多欄與表格可能錯字或順序不正確。姓名、數字與重要資訊請對照原稿。
