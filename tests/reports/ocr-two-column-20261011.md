# 中央分割雙欄 OCR：固定模擬文件比較

日期：2026-10-11。功能分支從 main `54bd95e` 建立，與 PR #4 分開。
本次只引用 PR #4 `4b435401c3f06e32c6d4edd47e94803b2a92af55` 的
`tests/support/scan-conditions.mjs`（byte-for-byte 相同），未更動該 PR。

## 結論與範圍

新增可選的「雙欄文件（中央分割，先左後右）」能改善這張中央留白、等行高的
橫排雙欄合成樣本。先切開左右影像，再分別以 PSM 4 辨識，保留原始文字並將
座標轉回完整頁面，得到 L1–L4、R1–R4 的八行文字。既有整頁自動／單欄路徑不變。

**實體掃描樣本為 0；這不是一般雙欄文件的準確率。** 本次不處理跨欄標題、
表格、非中央分欄、直排、三欄、手機透視或混合版面。沒有自動欄縫偵測，也沒有
改 CER 正規化、分母或距離計算；所有 CER 直接使用校對前 UI 原始文字。

## 原始版面分析

使用同一 PDF.js 渲染及正式辨識路徑，另行記錄 Tesseract 原始
`blocks → paragraphs → lines → words`；只向記憶體中的 served copy 加入記錄，
不修改回傳資料。自動 PSM 3 與單欄 PSM 4 都得到 **3 blocks、3 paragraphs、
4 lines**，各行包含左右兩欄內容。

第一行 bbox 為 `(153,148)–(1896,254)`，第三行為 `(156,632)–(1894,707)`，
單位為 2400×1500 OCR 圖像像素，均跨越中央 x=1200。
既有程式直接展開段落和文字行，因此排序這四個框無法產生八個正確欄內文字框。

詞級資料確實保留更多位置資訊，但框並不一律精確。例如第二行「公園」的框
`(1278,392)–(1896,467)` 延伸至右欄整行尾端，與後續詞框重疊。
以詞框拆分再重建閱讀順序仍需要額外的欄位與文字分組規則，不能將此樣本的
詞間空白當成通用欄位分隔符。因此本次選擇明確、可預期的選用式切圖辨識。

## 固定條件與結果

- 源圖：1600×1000、NotoSansCJKtc-Regular.otf、52px；左右各四行、共 64 中文字。
- PNG SHA-256：`13741b3c0ea34a40fe46923f30a390872e83d685576d13ea063b6015540bba13`，
  三種模式相同，也與 PR #4 樣本相同。
- PDF：576×360 pt，純圖片；辨識前以 PDF.js 確認沒有原生文字。
- OCR：300 DPI、maxEdge 3500，實際 2400×1500；雙欄各 1200×1500，無二次縮放。
- 語言：`chi_tra+eng`，沿用全部引擎、WASM、字型及語言檔。
- 本機：Node 24.19.0、Chromium 153.0.8010.0、Playwright 1.58.2。

| 模式 | UI 文字行數 | 閱讀順序 | CER |
|---|---:|---|---:|
| 自動 PSM 3 | 4 | L1,R1,L2,R2,L3,R3,L4,R4 | 0.718750 |
| 單欄 PSM 4 | 4 | L1,R1,L2,R2,L3,R3,L4,R4 | 0.718750 |
| 雙欄：先切圖、各用 PSM 4 | 8 | L1,L2,L3,L4,R1,R2,R3,R4 | 0.000000 |

前兩種模式都辨識出全部 64 個中文字，CER 46/64 反映錯序，不能稱為 71.875%
中文字形辨識錯誤。新增模式的 0 是對此固定 fixture 的觀察，不代表一般準確率。
功能初測與後續回歸的比較結果一致；未設計獨立三次重複量測，不將開發過程重跑
宣稱為統計上的穩定度證據。

## 座標與輸出驗證

左欄首行框為 `(36.72,36.48,147.84,18)` pt，右欄首行框為
`(307.44,36.48,147.60,17.52)` pt。右欄包含中央切割位移 288 pt，
不是錯放到左欄；八個框逐一對照源圖的欄位位置與行距。

正式 UI 端到端測試驗證：

1. 固定樣本的完整文字及八行先左後右順序；原始 TXT 與 UI 精確一致。
2. 未校對 PDF 的提取文字保持欄序，文字層為隱藏模式 3，可見像素與原 PDF 完全相同。
3. 八行都可編輯，儲存、關閉、重新開啟後內容保留；校對後 TXT 精確一致。
4. 校對後 PDF 的文字順序正確；每行 x、底端座標轉換與文字寬度均對應校對框
   （誤差 <0.1 pt），可見像素仍完全相同。
5. 開始處理右欄時按停止時，不保存該頁已完成的左欄；重新開始可完成整頁。

另有獨立像素級裁圖契約測試：101px 奇數寬度拆為 50+51，無漏失或重疊；
左欄空白不產生假文字，右欄缺少 blocks 時 fallback 僅涵蓋右欄；右欄失敗不回傳半頁。
此測試使用 worker spy，不計入真實 OCR 比較。座標映射與欄內排序另有 Node 單元測試。

原始資料見 [JSON](ocr-two-column-20261011.json)，包含 blocks／paragraphs／lines／
words 的文字、bbox、confidence，以及三種正式 UI 結果和框。詞級 symbols、基線等
未使用欄位不納入此精簡紀錄；報告不再重新排序或校正文字與座標。
